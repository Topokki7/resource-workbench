# 项目资源排期与成本情景工作台 · 交互原型

这是本地、无依赖的首个可交互原型。数据全部为合成案例，不连接真实工程、HR 或财务系统。

## 运行

推荐在本目录启动任意静态 HTTP 服务后访问 `index.html`。页面也可直接双击打开，但下载导出在部分浏览器的本地文件模式下可能受限制。

## 原型范围

- 全局总览与冲突处理随时切换
- 可缩放甘特图、完成后开始依赖、资源负荷热力图
- 成本构成与基线/情景对比
- 工期优先、成本优先、平衡、自定义护栏
- 角色切换、演示权限配置、权限变更记录
- 协作反馈、决策记录和 JSON 导出
- 浏览器本地存储；无真实账号、跨设备同步或外部通知

## 明确限制

- 首版只处理合成的固定工期、投入比例、角色日成本、任务固定费用和 FS 依赖。
- 不计算关键路径、收益、挣值、实际工资或自动最优排程。
- 调整资源投入不会自动缩短固定工期。
